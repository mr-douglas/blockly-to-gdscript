Physics course · Lesson 4

Drop a crate in 3D

Objective. Move the first lesson into 3D with RigidBody3D and a random rotation around all three axes.

Same idea, one more dimension

Compare this with lesson 1. RigidBody2D becomes RigidBody3D, the shape is a BoxShape3D, and positions use Vector3. In 2D a body can only spin one way, so its rotation is a single number. In 3D it can spin around the x, y and z axes, so rotation is a Vector3 of three angles.

crate.rotation = Vector3(randf_range(0, TAU), randf_range(0, TAU), randf_range(0, TAU))

The crate and the grassy island are models from Kenney’s Platformer Kit. crate_art() stretches the crate model to match the collision box exactly.

Predict, change, and test

  1. Set the rotation to Vector3(0, randf_range(0, TAU), 0). Predict how it lands now.
  2. Change shape.size to Vector3(2, 0.5, 1). What happens to the picture?
  3. Add crate.mass = 10. Does a heavier crate fall faster?
Check the prediction

Turning only around the y axis (up) spins the crate like a turntable, so it still lands flat. The model stretches to fit any box size. Mass does not change how fast things fall: without air resistance, heavy and light bodies fall together.

Success criteria. The crate lands differently each time you press R, and you can name the three rotation axes.

Apply it to your project. In a 3D scene, add a RigidBody3D with a MeshInstance3D (or an imported model) and a CollisionShape3D. Put a StaticBody3D floor below it and run the scene.
