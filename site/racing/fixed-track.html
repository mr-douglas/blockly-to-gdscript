Racing course · Lesson 1

Drive two cars on one track

Objective. Use two sets of input actions to control two CharacterBody3D cars through one reusable function.

Share the movement code and separate the controls

Both cars use the same drive() function. Give each call its own body and input values. The camera is orthographic, so objects stay the same size with depth. Its position, rotation and size stay fixed, and the whole track stays visible.

func drive(car: CharacterBody3D, turn: float, throttle: float, delta: float) -> void:
    car.rotate_y(turn * TURN_SPEED * delta)
    car.velocity = -car.transform.basis.z * throttle * SPEED
    car.move_and_slide()

Predict, change, and test

  1. Move the gold car with arrows and the blue car with WASD. Predict what happens when only one player presses forward.
  2. Swap the two bodies passed to drive(). Test the controls, then restore the original calls.
  3. Change TURN_SPEED and compare both cars on the same corner. Drive a practice lap with each car.
Check the prediction

Only the car passed the active input moves. Swapping the bodies swaps the control sets. Changing TURN_SPEED affects both cars because both use drive().

Success criteria. Each player can drive independently, both can move at once, and the shared camera shows the whole track.
