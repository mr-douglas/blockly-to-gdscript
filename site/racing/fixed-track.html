Racing course · Lesson 1

Drive two cars on one track

Objective. Use two sets of input actions to control two CharacterBody3D cars through one reusable function.

Share the movement code and separate the controls

Both cars use the same drive() function. Give each call its own body and input values. The camera uses a perspective view. It sits above and behind the track and tilts down to look at it, so cars further away look smaller. Its position and angle stay fixed, and the whole circuit stays visible.

func drive(car: CharacterBody3D, turn: float, throttle: float, delta: float) -> void:
    car.rotate_y(turn * TURN_SPEED * delta)
    car.velocity = -car.transform.basis.z * throttle * SPEED
    car.move_and_slide()

The cars are imported 3D models. make_car() gives each body a box-shaped collision shape and adds a model on top. The Kenney cars face +Z, so the model turns half a circle (PI) to face Godot's forward direction, −Z.

Predict, change, and test

  1. Move the orange car with the arrow keys and the green car with WASD. Predict what happens when only one player presses forward.
  2. Swap the two bodies passed to drive(). Test the controls, then restore the original calls.
  3. Change TURN_SPEED and compare both cars on the same curve. Drive a practice lap with each car.
  4. Change CAMERA_AT to Vector3(0, 20, 0.1). Compare the near-overhead view with the angled view, then restore it.
Check the prediction

Only the car passed the active input moves. Swapping the bodies swaps the control sets. Changing TURN_SPEED affects both cars because both use drive(). Moving the camera overhead flattens the scene. The angled view shows the height of the cars, barriers and trees.

Success criteria. Each player can drive independently, both can move at once, and the fixed camera shows the whole track.

Apply it to your project. Create separate input actions for each player in Godot. Reuse one movement function by passing the correct body and input values into it.
