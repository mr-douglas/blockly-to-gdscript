Scope and constants

Learning objective. Distinguish local variables, member variables and constants.

Read the example

GDScript

extends Node

const POINTS_PER_COIN = 5
var score = 0

func collect_coin():
    var bonus = 2
    score += POINTS_PER_COIN + bonus

func _ready():
    collect_coin()
    collect_coin()
    print(score)
  • Computer science. Scope means where a name can be used. A constant names a value that stays fixed.
  • GDScript. A var inside a function is local to that function or block. A var outside the functions belongs to the node. Set a fixed rule with const.
  • Godot. A player node can keep score between function calls. A bonus calculated inside one call can stay local.

Predict the output

After one call, what can _ready() read, and what will it print?

extends Node

const POINTS_PER_COIN = 5
var score = 0

func collect_coin():
    var bonus = 2
    score += POINTS_PER_COIN + bonus

func _ready():
    collect_coin()
    print(score)
Check the prediction

It reads the member variable score and prints 7. The local bonus stays inside collect_coin().
