Refactoring and readable code

Learning objective. Remove duplication and improve names while keeping the same behaviour.

Read the example

GDScript

extends Node

const POINTS_PER_COIN = 5

func reward(coins: int) -> int:
    return coins * POINTS_PER_COIN

func _ready():
    print(reward(2))
    print(reward(4))
  • Computer science. Refactoring improves the structure of a program. Existing test results should stay the same.
  • GDScript. Use meaningful names, consistent indentation, and constants for shared rules. Keep comments that explain why a rule exists.
  • Godot. Clean up duplicated score logic so later changes can be made in one place.
