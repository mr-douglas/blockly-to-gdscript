Boolean logic

Learning objective. Combine and reverse true-or-false conditions for game rules.

Read the same program in two forms

GDScript

print(true and false)
  • Computer science. A boolean expression produces true or false. A game can combine smaller tests to decide whether an action is allowed.
  • GDScript. and needs both sides to be true. or needs at least one side to be true, and allows both. not reverses a boolean. Use parentheses to make the order clear when combining tests.
  • Godot. A locked level could allow entry with a key or a pass, as long as the game is not paused.

Predict the output

Read the three expressions. Which lines will print true?

var has_key = true
var has_pass = false
print(has_key and has_pass)
print(has_key or has_pass)
print(not has_pass)
Check the prediction

The results are false, true, and true in that order.

Guided task · Allow either item

Change the operator so a player who has just the pass can enter. The program should print true.

var has_key = false
var has_pass = true
print(has_key and has_pass)

Debugging task · Pause the action

The player may jump only while grounded and while the game is running. Fix the expression so it prints false when the game is paused.

var grounded = true
var paused = true
print(grounded and paused)
Show a hint

Use not paused to test whether the game is running.

Independent task · Write a gate rule

Use and, or and not to print whether a player can enter. They need a key or a pass, and the game must be running. Test with just a key, with pause on, and with neither item.

var has_key = true
var has_pass = false
var paused = false
# Print whether entry is allowed.

Success criteria. With just a key and the game running, the code prints true. With pause on or with neither item, it prints false.
