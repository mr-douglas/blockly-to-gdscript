Randomness and probability

Learning objective. Choose a random range and explain the chance of a game result.

Read the example

GDScript

var roll = randi_range(1, 10)
print(roll >= 1 and roll <= 10)
  • Computer science. For an equally likely roll from 1 to 10, two winning numbers give two chances out of ten, or 20%. A short run may give a different result.
  • GDScript. randi_range(1, 10) chooses an integer and includes both ends. The example prints whether its result is inside the range.
  • Godot. Choose loot or enemy actions using rolls. Compare chances for the player and check that rules feel fair.

Predict the output

For each possible roll from 1 to 4, will a gem drop?

for roll in range(1, 5):
    print(roll <= 2)
Check the prediction

It prints true twice, then false twice. Two of the four rolls drop a gem.

Guided task · Set a 20% chance

The loop checks all ten possible rolls. Change the threshold so exactly two give a gem.

var gems = 0
for roll in range(1, 11):
    if roll <= 4:
        gems += 1
print(gems)

Debugging task · Include the low roll

Fix the rule so roll 1 is a winning roll. Run the test and check it prints true.

var roll = 1
print(roll < 1)

Independent task · Check a six-sided roll

Use randi_range() to roll 30 times. Track whether every roll was from 1 to 6, and print that result.

# Test 30 rolls. Print one true-or-false result.

Success criteria. Your range test prints true. You can name the values that would win under your drop rule and calculate the chance.
