Validation and defensive programming

Learning objective. Check inputs before using them and keep game values in range.

Read the example

GDScript

var health = 4
var damage = 7
health = max(0, health - damage)
print(health)
  • Computer science. Validation checks that a value meets your rules before code uses it. Decide what your program should do when the value is invalid.
  • GDScript. Use max(0, value) to set a lower limit. Check array indexes on both sides. dictionary.get(key, fallback) supplies a value when a key is missing.
  • Godot. Protect health, menu slot choices and item records when the game receives unexpected values.

Guided task · Keep health at zero or above

Change the assignment so damage cannot make health negative.

var health = 4
var damage = 7
health = health - damage
print(health)
