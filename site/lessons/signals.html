Signals

Learning objective. Connect a signal to a function and explain when it runs.

Read the example

GDScript

extends Node

signal key_found(key_name: String)

func show_pickup(key_name: String) -> void:
    print("Found " + key_name)

func _ready():
    key_found.connect(show_pickup)
    key_found.emit("silver key")
  • Computer science. A signal is a notification. A sender announces an event and a connected listener handles it.
  • GDScript. Use signal to declare a signal. connect() takes the function itself, without parentheses. emit() sends the notification and any values.
  • Godot. Buttons already have a pressed signal. Collision areas can signal when bodies enter. This lesson emits signals in code so you can test the handlers in the browser.

Predict the output

Which messages appear, and when does show_pickup() run?

extends Node

signal key_found(key_name: String)

func show_pickup(key_name: String) -> void:
    print("Found " + key_name)

func _ready():
    key_found.connect(show_pickup)
    key_found.emit("red key")
    key_found.emit("blue key")
Check the prediction

Each emit calls the connected function once. It prints Found red key, then Found blue key.
