Parameters and return values

Learning objective. Write and call a function that takes inputs and returns a result.

Read the example

GDScript

extends Node

func remaining_health(health: int, amount: int) -> int:
    return health - amount

func _ready():
    print(remaining_health(10, 3))
  • Computer science. A parameter names an input. A return value is the result of the call.
  • GDScript. In func remaining_health(health: int, amount: int) -> int:, the two names are parameters. The arrow gives the result type. return hands a value back to the caller.
  • Godot. Reuse a damage calculation for different players, enemies and attack strengths.

Predict the output

Predict the two results. Which parameter changes between calls?

extends Node

func remaining_health(health: int, amount: int) -> int:
    return health - amount

func _ready():
    print(remaining_health(10, 0))
    print(remaining_health(10, 10))
Check the prediction

It prints 10 then 0. The second argument changes from 0 to 10.
