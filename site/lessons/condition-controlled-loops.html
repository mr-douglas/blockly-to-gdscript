Condition-controlled loops

Learning objective. Use while for a repeated action and explain why the loop stops.

Read the example

GDScript

var charge = 3
while charge > 0:
    print(charge)
    charge -= 1
print("Empty")
  • Computer science. A condition-controlled loop repeats while its test is true. If the test is false at the start, the body runs zero times.
  • GDScript. Write while condition: and indent the body. Update a value in the body so the test can eventually become false.
  • Godot. A game might spend energy while enough remains to pay for the next action. Keep this test in a small script so you can inspect its output.

Predict the output

What prints? Can the loop run with energy exactly equal to the cost?

var energy = 4
while energy >= 2:
    energy -= 2
    print(energy)
Check the prediction

It prints 2 then 0. With 2 energy, the condition is still true because the comparison includes equality.
