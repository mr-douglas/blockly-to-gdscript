Input and events

Learning objective. Distinguish reacting to one key event from checking input every frame.

Read the example

GDScript

extends Node

func _unhandled_key_input(event: InputEvent) -> void:
    if event is InputEventKey and event.pressed and event.keycode == KEY_SPACE:
        print("Jump")

func _ready() -> void:
    var sample = InputEventKey.new()
    sample.keycode = KEY_SPACE
    sample.pressed = true
    _unhandled_key_input(sample)
  • Computer science. An event reports something that happened. A continuous check asks about the current state each time it runs.
  • GDScript. event.pressed tells you whether it was a press. event.keycode identifies the key. Comparing both lets the code react to one kind of event.
  • Godot. Godot can call _unhandled_key_input() for a key event. This browser lesson creates sample events in code. For a held action, use Input.is_action_pressed() in a frame callback in Godot.
