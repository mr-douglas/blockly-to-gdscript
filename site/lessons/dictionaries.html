Dictionaries and structured data

Learning objective. Create and update a game record using keys.

Read the example

GDScript

var enemy = {"name": "Bat", "health": 5}
print(enemy["name"])
  • Computer science. A dictionary maps keys to values. Use a key when a field has a meaningful name.
  • GDScript. Use braces and write each pair as "key": value. Read or update a field with enemy["health"].
  • Godot. Group values for one enemy, item, or level setting so they travel together.

Predict the output

What changes after the attack?

var enemy = {"health": 5, "damage": 2}
enemy["health"] -= 2
print(enemy["health"])
print(enemy["damage"])
Check the prediction

It prints 3 and then 2. Only the value under the health key changes.
