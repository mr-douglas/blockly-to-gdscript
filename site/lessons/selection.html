Selection

Learning objective. Use conditions and indentation to run one branch of code.

Read the same program in two forms

GDScript

var score = 10
if score >= 10:
    print("You win!")
else:
    print("Keep collecting!")
  • Computer science. Selection means a program chooses what to do based on a condition.
  • GDScript. if checks the first condition. elif checks another condition if the earlier ones were false. else is the fallback. End each header with a colon and indent the statements in its branch.
  • Godot. A game can give different feedback as a player gets closer to a goal.

Predict the output

Trace the branches at score 7. Which message appears? Which branch would run at score 10?

var score = 7
if score >= 10:
    print("Goal reached")
elif score >= 5:
    print("Halfway")
else:
    print("Keep going")
Check the prediction

At 7, Halfway prints. At 10, the first branch prints Goal reached and the other branches are skipped.

Independent task · Choose a medal

Print Gold for 10 or more coins, Silver for 5 to 9, and No medal for anything lower. Test at 4, 5, 9 and 10 coins.

Success criteria. The four test values give No medal, Silver, Silver, and Gold respectively. Each test prints one message.
