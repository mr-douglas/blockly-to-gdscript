State machines

Learning objective. Represent named states and test transitions between them.

Read the example

GDScript

extends Node

enum State { IDLE, MOVING, PAUSED }
var state = State.IDLE

func handle(action: String) -> void:
    match state:
        State.IDLE:
            if action == "walk":
                state = State.MOVING
        State.MOVING:
            if action == "pause":
                state = State.PAUSED
        State.PAUSED:
            if action == "resume":
                state = State.MOVING

func _ready():
    handle("walk")
    print(state == State.MOVING)
  • Computer science. A state machine has a current state and rules for changing it in response to an action.
  • GDScript. enum names the possible states. match state: picks the branch for the current state. An assignment such as state = State.MOVING changes it.
  • Godot. Movement, combat, and menus can use states such as idle, moving, paused or game over.
