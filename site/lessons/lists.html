Lists and arrays

Group inventory items in order.

GDScript

var inventory = ["coin", "key", "potion"]
print(inventory)

A Blockly list becomes an Array in GDScript. Use square brackets around the items. GDScript counts positions from zero, so inventory[0] is "coin".

Try it

Edit and run the example above, or follow the setup instructions to try it in Godot on your computer.

Print only the key by using its index. Then add inventory.append("map") and print the new last item.

Check your result

Use print(inventory[1]) for the key and print(inventory[3]) for the map.
