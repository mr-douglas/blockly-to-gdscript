Searching, sorting and high scores

Learning objective. Use linear search and sort scores into leaderboard order.

Read the example

GDScript

extends Node

func find_score(scores: Array, target: int) -> int:
    for index in range(scores.size()):
        if scores[index] == target:
            return index
    return -1

func _ready():
    print(find_score([12, 7, 12], 12))
    print(find_score([12, 7, 12], 2))
  • Computer science. Linear search checks entries in order, one at a time. Sorting puts all entries into a chosen order.
  • GDScript. Return the index as soon as the target matches. Use -1 to signal a missing score. sort() orders an array from low to high; reverse() reverses that order.
  • Godot. Search for a score or rank, and sort a score list before displaying it.

Debugging task · Check more than the first entry

The missing result is returned too soon. Remove the return inside the loop. Keep the final return for a missing score.

extends Node

func find_score(scores: Array, target: int) -> int:
    for index in range(scores.size()):
        if scores[index] == target:
            return index
        return -1
    return -1

func _ready():
    print(find_score([12, 7, 12], 7))
