Coordinates and vectors

Learning objective. Use Vector2 to move a point and measure the distance to a target.

Read the example

GDScript

var point = Vector2(10, 20)
point += Vector2(5, -3)
print(int(point.x))
print(int(point.y))
  • Computer science. Coordinates give a position. Adding a displacement changes the position by that amount in each direction.
  • GDScript. Vector2(x, y) stores two numbers. Read them with .x and .y. Use start.distance_to(target) for straight-line distance.
  • Godot. In Godot 2D, x increases to the right and y increases down. A node’s position is relative to its parent.

Predict the output

Will this point move up or down? Predict its new y value.

var point = Vector2(20, 10)
point += Vector2(0, -5)
print(int(point.y))
Check the prediction

It moves up because y decreases. The new y value is 5.

Guided task · Move up

Change the displacement so the point moves 5 pixels up. The output should be 5.

var point = Vector2(20, 10)
point += Vector2(0, 5)
print(int(point.y))

Debugging task · Keep the starting offset

The marker should move 4 pixels right from x = 10. Fix the assignment so x becomes 14.

var marker = Vector2(10, 20)
marker = Vector2(4, 0)
print(int(marker.x))

Independent task · Measure a route

Start at (0, 0) and move 3 pixels right and 4 pixels down. Print the distance from the start to the new position.

# Use two Vector2 positions.

Success criteria. The distance is 5 pixels. You can identify which values give the horizontal and vertical changes.
