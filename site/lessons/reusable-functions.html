Functions

Learning objective. Define and call a reusable function.

Read the same program in two forms

GDScript

extends Node

func award_coin():
    print("+1 coin!")

func _ready():
    award_coin()
  • Computer science. A function groups statements under a name. A call runs that group.
  • GDScript. Define a function with func name(): and indent its body. Call it with name(). Keep function definitions at the same indentation level as _ready().
  • Godot. Godot calls _ready() when a node is ready. Call your own functions from there to test them.

Predict the output

How many times does the function body run?

extends Node

func flash():
    print("Shield")

func _ready():
    flash()
    flash()
Check the prediction

It prints Shield twice. Defining the function adds no output; each call runs it once.
