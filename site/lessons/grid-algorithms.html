Grid-based algorithms

Learning objective. Index cells in a nested array and visit every cell in a grid.

Read the example

GDScript

var grid = [[0, 1, 0], [1, 1, 0]]
var walls = 0
for row in grid:
    for tile in row:
        if tile == 1:
            walls += 1
print(walls)
  • Computer science. A grid stores rows of cells. Use a row and a column to find a cell. The outer loop visits rows, and the inner loop visits cells in each row.
  • GDScript. Use grid[row][column]. Both indexes start at zero. In this model 0 means floor and 1 means wall.
  • Godot. Test a maze as data before deciding how to draw its tiles.

Predict the output

What is at row 1, column 2? Remember to start counting at zero.

var grid = [[0, 1, 0], [1, 1, 0]]
print(grid[1][2])
Check the prediction

It prints 0. The second row is [1, 1, 0].

Guided task · Read a wall cell

Change the lookup to read row 0, column 1. It should print 1.

var grid = [[0, 1, 0], [1, 1, 0]]
print(grid[0][0])

Debugging task · Fix swapped coordinates

The goal is row 0, column 2. Run the swapped lookup and fix the index order.

var grid = [[0, 1, 0], [1, 1, 0]]
print(grid[2][0])

Independent task · Count floor cells

Adapt the nested loop to count zeros. Try the starter grid and a grid made entirely of walls.

var grid = [[0, 1, 0], [1, 1, 0]]
var walls = 0
for row in grid:
    for tile in row:
        if tile == 1:
            walls += 1
print(walls)

Success criteria. The starter grid has 3 floor cells, and the all-wall grid has 0.
