Debugging and tracing

Learning objective. Tell syntax, runtime and logic errors apart and use tracing to locate a faulty step.

Read the example

GDScript

var score = 2
print(score)
score += 3
print(score)
score += 4
print(score)
  • Computer science. A trace records intermediate values. Compare the first wrong value with the statement that produced it.
  • GDScript. A syntax error stops the code being read. A runtime error happens during execution. A logic error gives the wrong result even when the code runs.
  • Godot. In Godot, read the error and line number first, then add temporary print statements to see how values change.

Predict the output

Which line first shows that the score is being replaced?

var score = 2
print(score)
score = 3
print(score)
score = 4
print(score)
Check the prediction

The correct trace would be 2, 5, 9. This prints 2, 3, 4, so the first update is already wrong.
