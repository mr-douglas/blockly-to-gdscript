Operators and expressions

Learning objective. Use arithmetic to calculate a value and comparisons to test a game rule.

Read the same program in two forms

GDScript

print(5 + 3)
  • Computer science. An expression gives you a value. An operator tells you what to do with one or more values.
  • GDScript. Use +, -, and * for arithmetic. Use >= for at least and == for equal. A comparison produces true or false. and combines two tests.
  • Godot. Calculate a score from coins and a bonus, or test whether enough points have been earned to open a gate.

Predict the output

What does each line print? Notice what the parentheses group.

print(2 + 3 * 4)
print((2 + 3) * 4)
print(10 >= 10)
Check the prediction

The lines are 14, 20, and true. Multiplication runs before addition unless parentheses group the addition. The comparison includes equality.

Guided task · Calculate a reward

Each coin is worth 5 points. Update the score expression so 3 coins and a bonus of 2 give 17 points.

var coins = 3
var bonus = 2
var score = coins + bonus
print(score)

Debugging task · Include the target score

A gate opens at 10 points or more. Run the code at 10 points, work out why it prints false, then fix the operator.

var score = 10
print(score > 10)
Show a hint

Use the operator that includes the case where both values are equal.

Independent task · Test a round result

Start with 12 health, subtract 4 damage, then print the health left. Print whether the player is still alive and has at least 10 points. Try with 10 points and again with 9.

var health = 12
var damage = 4
var score = 10
# Calculate and test the result.

Success criteria. With 10 points the two lines are 8 and true. With 9 points only the second line changes to false.
