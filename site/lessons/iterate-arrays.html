Iterating through arrays

Learning objective. Loop over an array and combine or select its values.

Read the example

GDScript

var enemies = ["bat", "slime"]
for enemy in enemies:
    print(enemy)
  • Computer science. Iteration processes each element of a collection, in order. An empty array has no elements to process.
  • GDScript. In for enemy in enemies:, enemy is the current value. It holds an item from the array itself.
  • Godot. Process each enemy in a wave, each inventory item, or each score in a round.

Predict the output

What gets added to total each time?

var scores = [2, 5, 3]
var total = 0
for score in scores:
    total += score
print(total)
Check the prediction

The total goes from 0 to 2, to 7, to 10. The final line prints 10.

Guided task · Print item names

Debugging task · Keep a running total

Fix the update so it adds every score instead of replacing the total.

var scores = [2, 5, 3]
var total = 0
for score in scores:
    total = score
print(total)

Independent task · Count strong scores

Count how many entries are at least 10. Test with the starter array and an empty array.

var scores = [5, 12, 10, 3]
# Count the entries that pass the test.

Success criteria. The starter scores give 2. An empty array gives 0 without an error.

Apply it to your project

Make an array of sample scores or items for your game. In _ready(), loop through the array to count the entries that meet one rule. Test with no entries as well. Godot editor setup

Optional extension

Track the sum of the scores that meet the rule, and print it alongside the count.
