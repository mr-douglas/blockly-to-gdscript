Decomposition and pseudocode

Learning objective. Turn a short plan into state, inputs, outputs and reusable functions.

Read the example

GDScript

extends Node

const GOAL = 3
var collected = 0

func collect_coin() -> void:
    collected += 1

func goal_met() -> bool:
    return collected >= GOAL

func _ready():
    for coin in range(3):
        collect_coin()
    print(goal_met())
  • Computer science. Decomposition breaks a feature into small jobs. Pseudocode describes the steps in plain language before you write them in GDScript.
  • GDScript. A comment can record the plan. A named function can implement each job. In the example, store the count, repeat collection, test the goal and print the result.
  • Godot. Prototype a rule in _ready(). Later, a pickup signal can call the same collection function.
