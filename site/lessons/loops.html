Repeat loops

Repeat an action a fixed number of times.

GDScript

for i in range(3):
    print("Spawn a coin!")

The Blockly repeat count goes inside range(). The indented body runs once per value. Here, i takes the values 0, 1, and 2.

Try it

Edit and run the example above, or follow the setup instructions to try it in Godot on your computer.

Change the count to five. Replace the print line with print("Coin ", i + 1) to number each coin in the Output panel.

Check your result

The labels should go from Coin 1 through Coin 5. This exercise prints spawn messages. Later, the loop body could instantiate actual coin scenes.
