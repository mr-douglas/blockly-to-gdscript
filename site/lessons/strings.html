Strings and player-facing text

Learning objective. Join text and values to produce readable game messages.

Read the example

GDScript

var pilot = "Mina"
print("Hello, " + pilot + "!")
  • Computer science. A string is a sequence of characters. Spaces and punctuation are characters, too.
  • GDScript. Put text in quotes. Use + to join strings and str() to convert a number to text.
  • Godot. Build the text for dialogue, a score label, or a short instruction.

Predict the output

Predict the spaces and punctuation in the output.

var coins = 3
print("Coins: " + str(coins) + "/5")
Check the prediction

It prints Coins: 3/5. The space after the colon is inside the first string.
