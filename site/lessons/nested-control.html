Nested control structures

Learning objective. Use selection inside iteration and trace which statements run.

Read the example

GDScript

for wave in range(3):
    if wave == 1:
        print("Boss")
    else:
        print("Enemy")
  • Computer science. Nesting puts one control structure inside another. The program can make a fresh decision on every loop step.
  • GDScript. Indent the if and else one level inside the for. Indent each branch’s body one more level.
  • Godot. A wave plan can spawn a different enemy on a chosen wave.

Predict the output

Which wave is special, and how many lines print?

for wave in range(1, 4):
    if wave == 3:
        print("Boss")
    print(wave)
Check the prediction

It prints 1, 2, Boss, then 3. The last print() is in the loop and outside the branch.

The warning should appear once, on the last wave. Fix the indentation.
