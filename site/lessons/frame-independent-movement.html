Frame-independent movement

Learning objective. Use delta to turn speed per second into a distance for one frame.

Read the example

GDScript

extends Node2D

var speed = 120.0

func _process(delta: float) -> void:
    position.x += speed * delta

func _ready() -> void:
    for frame in range(2):
        _process(0.5)
    print(roundi(position.x))
  • Computer science. The time between frames can change. Distance for one frame equals speed multiplied by elapsed time.
  • GDScript. Godot passes delta in seconds to _process(delta). Multiply a speed in pixels per second by delta and add that distance to position.
  • Godot. These console examples call _process() with sample times from _ready(). In a running scene, Godot calls _process() each frame.
