Switch between first and third person

Objective. Toggle which Camera3D is active without replacing the player or its movement.

One player and two cameras

Both cameras follow the same player. The first-person camera sits at eye level. The third-person camera sits on a SpringArm3D, which can shorten near obstacles. The Boolean first_person remembers the view. make_current() activates the chosen camera. Only the player’s art is hidden in first person; its collision shape still works.

func set_first_person(enabled: bool) -> void:
    first_person = enabled
    player_art.visible = not first_person
    var camera := eyes if first_person else chase
    camera.make_current()

Predict, change, and test

  1. Press C twice, then hold it down. Predict the number of switches. Move and jump in both views.
  2. Change set_first_person(false) in _ready() to set_first_person(true). Run the edit and test that C still switches back.
  3. Change arm.spring_length from 4.6 to 2.5. Compare how close the third-person view is. Test that first-person framing stays the same.
Check the prediction

Each press switches once; keyboard repeat is ignored by is_action_pressed() for this event. The initial Boolean sets the starting camera. The spring arm controls only the chase camera.

Success criteria. C switches both ways without resetting position or velocity. The player’s mesh is visible in third person, and collision and jumping work in both views.

Apply it to your project. Add an eye camera and a chase camera under the same CharacterBody3D. Bind C to an action named view, use a Boolean to choose the camera, and test the switch while moving.
