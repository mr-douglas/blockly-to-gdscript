Interface course · Lesson 1

Show the score in a HUD

Objective. Use a CanvasLayer, Control nodes and a Theme to show the score in a fixed corner of the screen.

Start from the finished platformer

This script extends the last lesson of the 2D platformer course, so the level, coins, hazards and locked exit are already there. Until now the labels were drawn as part of the level. A real game puts its interface on a CanvasLayer. That layer is drawn on top of the level and does not move when a camera moves.

Containers, anchors and a Theme

Every interface node is a Control. An HBoxContainer lines its children up in a row, so the apple icon and the count stay side by side. Anchors pin a Control to part of the screen: PRESET_TOP_RIGHT keeps the score in the top-right corner. A Theme set on the root Control is shared by every Control inside it, so one line changes the font everywhere.

ui_theme.default_font = PIXEL_FONT
ui_theme.default_font_size = FONT_SIZE
ui.theme = ui_theme
...
score_bar.set_anchors_and_offsets_preset(Control.PRESET_TOP_RIGHT, Control.PRESET_MODE_MINSIZE, 16)
score_bar.grow_horizontal = Control.GROW_DIRECTION_BEGIN

reparent() moves the existing coin and message labels from the level into the HUD. Their old font size override is removed first, because an override on a node always beats the Theme.

Predict, change, and test

  1. Collect a coin. Predict how the score text changes, and why it no longer says “Coins:”.
  2. Change FONT_SIZE to 48. Which pieces of text change size, and which do not?
  3. Change PRESET_TOP_RIGHT to PRESET_BOTTOM_RIGHT. Then try PRESET_TOP_LEFT and explain why grow_horizontal matters less there.
Check the prediction

This lesson’s collect_coin() calls the old version with super, then replaces the text with “collected / required”. Every label using the Theme gets bigger, but labels with their own font size override do not. The anchor preset moves the bar to a different corner.

Success criteria. The score stays in the corner, uses the pixel font and updates when a coin is collected.

Apply it to your project. In Godot, add a CanvasLayer to your level scene with a Control child set to Full Rect. Create a Theme resource, set its default font, and assign it to that Control. Add an HBoxContainer with a TextureRect and a Label, anchor it to a corner, and update the Label from your score code.
