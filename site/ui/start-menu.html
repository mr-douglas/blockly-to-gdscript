Add a start menu

Objective. Reuse a function to build a start menu that keeps the game paused until the player presses Play.

Same function, different arguments

The start menu is another panel, so this lesson calls make_panel() again with a new title, message, icon and function. show_panel() pauses the game straight away in _ready(). The level is drawn behind the menu but nothing moves. Pressing Play calls start_game(), which hides the menu and unpauses the game.

start_menu = make_panel("Frog Run", how_to_play, "Play", PLAY_ICON, start_game)
show_panel(start_menu)

func start_game() -> void:
    start_menu.hide()
    get_tree().paused = false

The \n in the message starts a new line. %d puts the value of REQUIRED_COINS into the text, so the menu stays correct if the number changes.

Predict, change, and test

  1. Before pressing Play, hold Right. Predict whether the frog moves. Then press Play.
  2. Lose all your hearts and press Try again. Predict which screen you see first, and explain why.
  3. Change the game’s title and the how-to-play text. Set REQUIRED_COINS to 2 and check that the menu updates.
Check the prediction

The frog cannot move while the menu is open because the game is paused. reload_current_scene() runs _ready() again, so the start menu appears again after a restart. The %d placeholder always shows the current value of the constant.

Success criteria. The game starts paused behind the menu. Play starts it with the mouse or the keyboard, and a restart returns to the menu.

Apply it to your project. Make a separate menu scene and set it as the main scene in Project Settings. Its Play button can call get_tree().change_scene_to_file() with the path of your level scene.
