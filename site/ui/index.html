Build a Game Interface

Take the finished level from Build a 2D Platformer and turn it into a complete game. You will add a heads-up display (HUD) for points and health, a game over screen, a start menu and a "You win" screen. Each lesson builds on the one before, using Godot’s Control nodes, containers, themes, buttons and signals.

  1. 1. Show the score in a HUD

    Use a CanvasLayer, containers, anchors and a Theme with a pixel font.

  2. 2. Show health with hearts

    Store health in a variable and draw it as a row of heart icons.

  3. 3. Pause the game and show a game over screen

    Build a panel with a button, pause the game, and restart the scene.

  4. 4. Add a start menu

    Reuse the panel function to wait for the player to press Play.

  5. 5. Finish with a "You win" screen

    Time the run and show the player’s results when they reach the trophy.
