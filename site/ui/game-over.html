Pause the game and show a game over screen

Objective. Build a panel with a button, pause the game behind it, and restart the scene when the button is pressed.

Build the panel in a function

make_panel() builds a PanelContainer holding a VBoxContainer with a title, a message and a Button. Each node is given a name, so other code can find it later with a path such as "Column/Button". The button’s pressed signal is connected to whichever function you pass in. The next two lessons reuse this function for the start menu and the win screen.

var button := Button.new()
button.name = "Button"
button.text = button_text
button.icon = icon
button.pressed.connect(on_pressed)

Pause, then restart

Setting get_tree().paused to true stops every node that is pausable: the player, the saw, the moving platform and their physics. The interface would stop too, so its process_mode is set to PROCESS_MODE_ALWAYS. grab_focus() lets Enter or Space press the button as well as the mouse. To restart, unpause and reload the whole scene.

func show_panel(panel: PanelContainer) -> void:
    panel.show()
    get_tree().paused = true
    panel.get_node("Column/Button").grab_focus()

func restart() -> void:
    get_tree().paused = false
    get_tree().reload_current_scene()

style_theme() adds StyleBoxFlat backgrounds to the Theme for panels and for each button state: normal, hover, pressed and focus.

Predict, change, and test

  1. Lose all three hearts. Predict what the saw and the moving platform do while the panel is open. Press Try again with the mouse, then test Enter.
  2. Comment out ui.process_mode = Node.PROCESS_MODE_ALWAYS. Lose again and try the button. Restore the line.
  3. Change the "hover" colour in style_theme() and move the mouse over the button to test it.
Check the prediction

Everything in the level freezes because it is paused. Without the process mode line the button is paused as well, so it cannot be clicked and the game is stuck. The hover colour appears only while the pointer is over the button.

Success criteria. At zero hearts the game freezes and the panel appears. The button works with the mouse and the keyboard and starts a fresh run.

Apply it to your project. In Godot, build the panel as its own scene and instance it in your HUD. Set its Process Mode to Always in the Inspector, connect the button’s pressed signal in the Node dock, and call reload_current_scene() to restart.
