Blockly to GDScript

Use blocks you already know to write your first Godot scripts. Edit and run code in your browser as you prototype the rules of a coin-collecting game.

  3. Data types

  4. Operators and expressions

  5. Selection

  6. Boolean logic

    Combine conditions with and, or and not.

  7. Count-controlled loops

  8. Condition-controlled loops

  9. Nested control structures

  10. Strings and player-facing text

  11. Arrays and inventories

  12. Iterating through arrays

  13. Dictionaries and structured data

  14. Functions

  15. Parameters and return values

Run the examples in the Godot editor

  1. Create a project. Add a plain Node as the root of a new scene and save it.
  2. Attach a GDScript to the root. Use the default extends Node line and add func _ready(): underneath.
  3. Put each lesson’s code inside _ready() by indenting it one level, unless the lesson gives you a whole script. Press F6 to run the current scene and read the Output panel.
