Blockly to GDScript

Use blocks you already know to write your first Godot scripts. Work through the lessons to prototype the rules of a coin-collecting game.

  1. Variables

    Store and display the player’s score.

  2. If and else

    Show a win message when the player reaches ten points.

  3. Repeat loops

    Repeat an action a fixed number of times.

  4. Functions

    Give a reusable action a name.

  5. Lists and arrays

    Group inventory items in order.

Get ready in Godot 4

  1. Create a project. Add a plain Node as the root of a new scene and save it.
  2. Attach a GDScript to the root. Use the default extends Node line and add func _ready(): underneath.
  3. Put each lesson’s code inside _ready() by indenting it one level, unless the lesson gives you a whole script. Press F6 to run the current scene and read the Output panel.
