Save a checkpoint

Objective. Store a new spawn position when the player touches a checkpoint.

Change the position used by respawn

The variable spawn_point starts at START. Touching the checkpoint stores a new Vector2 and raises its flag. The existing fall and hazard code both call respawn(), so both use the new position after the checkpoint is activated.

func respawn() -> void:
    player.position = spawn_point
    player.velocity = Vector2.ZERO

Predict, change, and test

  1. Walk into the gap before touching the checkpoint. Predict where you return.
  2. Jump the gap, touch the checkpoint pole so its flag rises, then walk into the spikes. Compare where you return.
  3. Move CHECKPOINT 20 pixels left. Predict how this affects the pole position and the respawn position, then test.
Check the prediction

The first fall returns you to the start. Once the flag is raised, a hazard returns you to the checkpoint. Changing CHECKPOINT moves both the pole and the saved position.

Success criteria. A fall before the checkpoint uses the start. A hit after the checkpoint uses the checkpoint. R resets the run to the start.

Apply it to your project. Place your checkpoint on a safe platform. Store its position separately from the player’s current position. Test a fall before and after it.
