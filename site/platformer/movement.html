Platformer course · Lesson 1

Read input and move sideways

Objective. Use held input and delta to move a character left and right at a steady speed.

Set up the scene

In Godot, start with a Node2D scene and a CharacterBody2D child for the player. Give the player a visible Sprite2D or Polygon2D. In the browser starter, _ready() makes these nodes for you. This step moves the character directly, so it can leave the screen. Press R to restart.

func _physics_process(delta: float) -> void:
    var direction := Input.get_axis("left", "right")
    player.position.x += direction * SPEED * delta

Input.get_axis() gives −1 for Left, +1 for Right, and 0 with neither or both. SPEED is in pixels per second. Multiplying by delta gives the distance for one physics tick.

Open the editable movement starter

Predict, change, and test

  1. At 180 pixels per second, predict how far the player travels while Right is held for half a second.
  2. Double SPEED. Run the edited code, hold Right for about the same time, and compare the movement.
  3. Make a one-line bug by swapping the two actions in get_axis(). Predict which way Right moves the player, test it, then repair the argument order.
Check the prediction

The first version moves about 90 pixels in half a second. Doubling the speed doubles the distance. Swapping the action arguments reverses the direction.

Success criteria. The player moves in the matching direction for each arrow and stops when you release it. You can explain why delta is needed when you update position directly.

Apply it to your project. Add actions named left and right in Project Settings → Input Map and bind them to the Left and Right arrow keys. Attach a script to your player, define SPEED, and use position.x in place of player.position.x. Test both keys.
