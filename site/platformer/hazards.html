Add hazards that reset the player

Objective. Use an overlap signal to trigger a respawn while keeping the score.

Reuse the respawn function

The row of spikes is an Area2D. The player can enter it, and the signal calls the same respawn() used for falls. call_deferred() waits until the collision query has finished before moving the player.

func on_hazard(body: Node2D) -> void:
    if body == player and not completed:
        respawn.call_deferred()

Predict, change, and test

  1. Cross the gap and walk into the spikes. Predict what happens to the coins you collected.
  2. Add a second hazard by calling add_hazard() again. Place it before the gap and check that you can still jump over it.
  3. Comment out respawn.call_deferred() and replace it with pass. Test the same spikes, then restore the original line.
Check the prediction

The player returns to the start and keeps the coins. The respawn changes position and velocity, and the score is stored separately.

Success criteria. Touching either hazard respawns the player. A successful jump clears it, and the coin total stays the same after a hit.

Apply it to your project. Add a hazard Area2D with a collision shape to your own scene. Connect its signal to your existing respawn handler and test the level with it in two places.
