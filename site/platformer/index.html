Build a 2D Platformer

Start with a character on an empty level and build up to a playable platformer. Each lesson adds one mechanic and lets you change the GDScript and play the result.

This course builds on From Blocks to GDScript, especially vectors, frame-independent movement, and input.

  1. 1. Read input and move sideways

    Move a visible character left and right.

  2. 2. Make walls solid

    Give the player and the level collision shapes.

  3. 3. Fall and land with gravity

    Accelerate downward and detect the floor.

  4. 4. Jump only from the floor

    Give the player an upward velocity when Space is pressed.

  5. 5. Recover after falling

    Jump a gap and return safely to the spawn point after a miss.

  6. 6. Finish the level with a signal

    Connect a goal trigger and test the completed level.

  7. 7. Collect coins and count them

    Add collectible items and display the running score.

  8. 8. Add hazards that reset the player

    Make a red hazard the player must jump over.
