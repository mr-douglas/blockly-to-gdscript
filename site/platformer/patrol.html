Make an enemy patrol

Objective. Move an enemy between two endpoints and change its target on arrival.

Keep track of the current target

A patrol has a position, a speed and a target. move_toward() approaches the target without overshooting. When the enemy arrives, set the target to the other endpoint. The spinning saw is a moving Area2D with the same contact behaviour as the spikes.

enemy.position.x = move_toward(enemy.position.x, target_x, PATROL_SPEED * delta)
if is_equal_approx(enemy.position.x, target_x):
    target_x = PATROL_LEFT if target_x == PATROL_RIGHT else PATROL_RIGHT

Predict, change, and test

  1. Watch the saw. Predict where it will turn around and what happens if it touches the player.
  2. Double PATROL_SPEED, then time a jump past the saw. Compare the two speeds.
  3. Change the endpoint spacing and test whether the level is still possible to finish.
Check the prediction

The saw reverses at the endpoints. Touching it triggers the same respawn as the spikes. Doubling speed reduces the time between turns.

Success criteria. The enemy reaches both endpoints repeatedly, and touching it sends the player to the active checkpoint.

Apply it to your project. Choose two safe endpoints for a patrol in your own level. Mark them in the editor and test the path at different speeds.
