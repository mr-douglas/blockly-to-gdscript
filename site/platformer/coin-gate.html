Unlock the exit with coins

Objective. Combine collision events and game state to enforce a win condition.

Check the score before completing the level

The exit uses the same body_entered signal as before. A new check reads the current score. If it is too low, show how many more coins are needed and return before completing the level. If it is high enough, call the existing finish handler.

if coins < REQUIRED_COINS:
    status.text = "Locked. Find %d more." % (REQUIRED_COINS - coins)
    return
super._on_goal_entered(body)

Predict, change, and test

  1. Reach the exit after missing the airborne coin. Predict the message and whether the run will count as complete.
  2. Collect all three coins and enter the exit again. Then press R and check the start of a fresh run.
  3. Change REQUIRED_COINS to 2 and try with exactly two coins. Test that the boundary is allowed and that one coin is still too few.
Check the prediction

The original exit stays locked with two coins and asks for one more. It completes with three. With the target set to two, two is enough and one is too few.

Success criteria. The exit rejects a score below the target, accepts the exact target, and resets with the rest of the level.
