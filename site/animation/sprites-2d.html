Import and play a 2D sprite sheet

Objective. Import a PNG strip, slice it into equal frames, and switch an AnimatedSprite2D between idle and run.

Turn each PNG strip into a SpriteFrames animation

Download the two Ninja Frog strips below and put them in your Godot project folder. Add an AnimatedSprite2D and create a SpriteFrames resource. In the SpriteFrames panel, add idle and run. For each animation choose Add frames from a sprite sheet, select its PNG and use one row with 11 columns for idle or 12 for run. Select the frames in order. Set looping on and set 10 FPS for idle and 14 FPS for run. For crisp pixel art set the sprite’s texture filter to Nearest. The browser starter slices the same sheets in GDScript with AtlasTexture.region.

var direction := Input.get_axis("left", "right")
if direction != 0.0:
    frog.flip_h = direction < 0.0
play_clip(&"run" if direction != 0.0 else &"idle")

Predict, change, and test

  1. Press Left, then Right, then release both. Predict the animation and which way the frog will face.
  2. Change RUN_FPS from 14 to 6. Compare how fast the feet move and how far the frog travels in one second.
  3. Temporarily turn off looping in add_strip(). Check what happens when you hold Right. Restore looping.
Check the prediction

The frog runs while moving and returns to idle when the key is released. Left flips the art. FPS changes the animation pace; MOVE_SPEED controls travel distance. The current play_clip helper restarts a finished clip when input still asks for it.

Success criteria. Both PNG strips are sliced into 32×32 frames. The correct clip plays for each input and the picture stays sharp when enlarged.

Apply it to your project. Build the same SpriteFrames resource in Godot. Attach code that uses the player’s input or velocity to select the clip, then try the sprite in a 2D scene.
