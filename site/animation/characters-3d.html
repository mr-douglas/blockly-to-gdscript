Import and animate a 3D character

Objective. Import a rigged GLB scene and switch named clips using its AnimationPlayer.

Import the model and inspect its clips

Copy the knight GLB into your Godot project. Double-click it in the FileSystem to open Advanced Import Settings. Preview the idle and walking animations and check their names. Drag the GLB into your own Node3D scene to create an instance. Expand it with Editable Children if you need to inspect the hierarchy. In this file the imported root contains AnimationPlayer, and deeper inside is Skeleton3D. The mesh is attached to that skeleton. The clips move its bones rather than replacing the image frame.

var direction := Input.get_axis("left", "right")
play_clip(WALK if direction != 0 else IDLE)

func play_clip(wanted: StringName) -> void:
    if animator.current_animation != wanted:
        animator.play(wanted, 0.18, PLAYBACK_RATE)

Predict, change, and test

  1. Run the starter, press Right, then release it. Predict which clip will play at each stage.
  2. Change PLAYBACK_RATE to 0.5. Compare how fast the legs move with how far the character travels.
  3. Change WALK to HumanArmature|Run. Use the exact spelling shown in the imported clip list. Run the edit and compare the gait.
Check the prediction

The knight starts in Idle, plays Walking while you hold a direction, and returns to Idle when you release it. Playback rate changes clip speed. MOVE_SPEED controls travel. The second argument to play() blends the outgoing and incoming clips for 0.18 seconds.

Success criteria. Godot imports the rig and clips. The scripted transition plays the correct clip, and you can change the clip or its rate without changing travel speed.

Apply it to your project. Instance the GLB in your own scene. Use get_animation_list() to check the names, enable looping on your locomotion clips in the import settings or through code, and call play() from a script on the parent scene. Test idle, movement and stopping.
