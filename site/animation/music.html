Loop background music

Objective. Import a music track, make it loop without a gap, and control its playback and volume from code.

Make the track loop

Music is played by an AudioStreamPlayer, just like a sound effect. The difference is that it should start again when it reaches the end. OGG music can loop in two ways. In the editor, select the file, tick Loop in the Import dock and press Reimport. In code, set loop on the stream before playing it. These tracks were written to loop seamlessly, so the join cannot be heard.

func play_track(index: int) -> void:
    track = index
    var stream: AudioStreamOggVorbis = TRACKS[index]
    stream.loop = LOOP_MUSIC
    music.stream = stream
    music.play()

Pause, volume and the playback position

stream_paused pauses the music and keeps its place. volume_db is measured in decibels: 0 is full volume, and each step of −6 dB roughly halves how loud it sounds. get_playback_position() reports how many seconds into the track the player is.

if Input.is_action_just_pressed("action"):
    music.stream_paused = not music.stream_paused
if Input.is_action_just_pressed("down"):
    music.volume_db = maxf(music.volume_db - VOLUME_STEP, QUIETEST)

Predict, change, and test

  1. The title track lasts about 11 seconds. Watch the timer as it reaches the end and listen to what happens.
  2. Set LOOP_MUSIC to false and run again. Predict what the status shows after 11 seconds.
  3. Press Down several times, then Space twice. Check whether the volume and the position in the track are kept.
Check the prediction

With loop on, the timer returns to 0:00 and the music continues without a gap. With loop off, the player stops at the end and the status changes to Stopped. Pausing keeps both the position and the volume.

Success criteria. The music loops with no gap. You can switch tracks, pause and resume, and change the volume without restarting the track.

Apply it to your project. Import a looping track and turn on Loop in its import settings. Add an AudioStreamPlayer with Autoplay on to your main scene. Set its volume_db lower than your sound effects so the music stays in the background.
