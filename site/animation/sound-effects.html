Import and play sound effects

Objective. Import short sounds and play them from code at the moment something happens in the game.

Import the sounds and add a player for each

Download the three OGG files below and drag them into your Godot project’s FileSystem dock. Godot imports them as AudioStreamOggVorbis resources. A sound file cannot play by itself. It needs an AudioStreamPlayer node with the file set as its stream. In the editor, add one AudioStreamPlayer per sound and drag the file onto its Stream property. The browser starter does the same in add_sound().

func add_sound(stream: AudioStream) -> AudioStreamPlayer:
    var sound := AudioStreamPlayer.new()
    sound.stream = stream
    add_child(sound)
    return sound

Play each sound at the right moment

Call play() in the same place as the action it belongs to: the jump sound where the jump starts and the coin sound where the coin is collected. Landing has no input of its own, so the code compares this frame with the last one. If the frog is on the floor now but was not before, it has just landed. Changing pitch_scale a little each time stops a repeated sound from becoming tiring.

if Input.is_action_just_pressed("action") and player.is_on_floor():
    player.velocity.y = -JUMP_SPEED
    play_varied(jump_sound)
player.move_and_slide()
if player.is_on_floor() and not was_on_floor:
    land_sound.play()
was_on_floor = player.is_on_floor()

Predict, change, and test

  1. Jump five times in a row and listen. Then set PITCH_VARIATION to 0.0 and compare.
  2. Set PITCH_VARIATION to 0.5. Predict how the coin sound will change, then test it.
  3. Comment out was_on_floor = player.is_on_floor(). Predict when the landing sound plays now, test it, and restore the line.
Check the prediction

With no variation every jump sounds identical. A large variation makes some coins sound much higher or lower, which can seem like a different sound. Without updating was_on_floor it stays true from the start, so the landing check is never true and the landing sound never plays.

Success criteria. Each sound plays once, at the moment of its action, and repeated sounds vary slightly.

Apply it to your project. Import at least three sounds and give each its own AudioStreamPlayer. Play them from the code that handles each event. Use volume_db to balance them so no sound drowns out the others.
